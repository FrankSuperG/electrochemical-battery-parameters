Selected original CSV, MAT, MATLAB text and API metadata are retained byte-for-byte
with checksum pins. E-BatP changes: renamed normalized CSV channels; split
incremental full-cell OCV at the first maximum stored charge into two branches
with explicit passed-capacity transformations; exported nine native minor-loop
arrays separately; copied native OCPn nodes without fitting or resampling.
No source code is executed, measured current synthesized, temperature trace
invented, or simulation prediction imported as observation. OCPn tables are
parameterized model inputs, not raw measured electrode OCP/GITT points. Catalog
interpolation does not reproduce the complete author's model or extrapolation.
