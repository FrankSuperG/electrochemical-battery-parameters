# Data repository for 'Multiscale coupling of surface temperature with solid diffusion in large lithium-ion pouch cells'

A pre-print of the publication that refers to this data may be found at https://arxiv.org/abs/2109.12903. This data repository contains the measurement data used in the research. Four battery cells were tested in the research (these are labelled Cell D, Cell E, Cell F and Cell I respectively). The file names first indicate the cell in question, then the experimental conditions. For example 'Cell_I_30pcSOC2C100s.mat' is a dataset recorded using Cell I, at 30% state of charge, with 2C rate, and 100 second pulses.

All data are in the form of Matlab `.mat` binary files. When loaded into the Matlab workspace, the user will see an `x` by `y` by `t` matrix of infra-red thermal imaging data called temperature (where `x` and `y` are the spatial dimensions and `t` is the time dimension), a vector of voltage data (`v` by `t`) called voltage, and a vector of current data (`i` by `t`) called current. All vectors are synchronised in time to a 1 Hz timebase.
