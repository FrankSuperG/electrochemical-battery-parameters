开始使用 04

在 Python 中读取。

from ebp import Catalog

catalog = Catalog()
curve = catalog.get("lfp-afshar2017-formula")
voltage = curve(0.5)
records = catalog.search(material="LFP")

理解数据的适用范围。

  • C/50 实测分支是伪 OCP，仍包含有限电流极化。
  • 分支归一化容量从 0 到 1 表示该分支的测试进程；嵌锂和脱锂方向未强制反转或配平。
  • 室温没有被补写为 25°C；未知温度保留为空。
  • 导入 PyBaMM 时，容量轴曲线需要用户提供有依据的化学计量比映射。
  • v0.1 提供 OCP 组件，尚无完整电芯参数集及独立全电池验证。
