Start using the data 05

Read it in Python.

from ebp import Catalog

catalog = Catalog()
curve = catalog.get("bpx-lfp18650-lfp-ocp")
voltage = curve(0.5)
parameters = catalog.search_parameters(
    cell_id="a123-amp20m1hd-a",
    category="diffusion",
)
tests = catalog.linked_tests("a123-amp20m1hd-a")

Use the right assumptions.

  • C/50 measurements are pseudo-OCP branches with finite-current polarization.
  • BPX OCP fits retain their supplied operating stoichiometry bounds.
  • The AMP20 diffusivity is derived from a fitted time and an assumed radius; both electrodes share that effective time.
  • Volumetric kinetics, surface exchange-current densities and BPX rate constants have different definitions.
  • A shared cell model or study does not establish identical specimens.
  • Missing measurements remain empty; unknown identities, conditions and licenses remain explicit gaps.
