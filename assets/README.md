# E-BatP identity

`logo.png` is the README lockup; `src/ebp/web/logo.png` is the identical packaged viewer asset. The original project asset is distributed under MIT.

Created with the built-in ImageGen tool in generation mode, using the Electrochemical Battery Model Atlas identity as a visual style reference. The brief requested one wide GitHub README lockup with the exact text **E-BatP** and **Electrochemical Battery Parameters**, navy linework and muted teal, a cylindrical battery over three data layers, electrode particles and an OCP-like curve, on white. Flat, clean, vector-like appearance; no gradient, shadow, texture or watermark. It is a companion identity for this repository, with data layers replacing the Atlas open-book motif.

The shipped PNG is a generated raster image. It is not experimental data or a scientific plot.
