# Panasonic NCR18650B: tests, half-cell leads and ageing

[NCA source table](../data/full-cell/NCA.md) · [All dataset links](../data/full-cell/README.md) · [File locator CSV](../data/full-cell/files.csv) · [Source-review metadata](../src/ebp/data/evidence/ncr18650b-source-review.json)

Four independent sources identify Panasonic NCR18650B. They complement one
another for discovery, but do not form a shared-specimen parameter package.
Common manufacturing batch, state of health, donor serial and transferable
electrode parameters are not established across studies. Source capacity ratings
are retained rather than forced to agree. The previous
[Malaya source](../data/full-cell/malaya-three-chemistries-2022.md) also names
NCR18650B, but its inner per-cell files remain unverified.

## Same-study half-cell and full-cell RPT

[Zenodo 60232](https://zenodo.org/records/60232) contains
`Panasonic_NCR18650B_formation_and_RPT_tests.zip`. Its complete central directory
was inspected with the [bounded archive tool](../scripts/inspect_external_archives.py):
262 entries, including 158 MAT files (100 full-cell FORM, 56 full-cell RPT and two
half-cell RPT). File counts do not establish independent branches or donor joins.
Selected paths inside the parent ZIP:

```text
Upload/Half cell/NE/[01] RPT.mat
Upload/Half cell/PE/[02] RPT.mat
Upload/Full cell/NCRB001/[00] FORM.mat
Upload/Full cell/NCRB001/[01] RPT.mat
Upload/Full cell/NCRB002/[01] RPT.mat
```

The [same-study paper](https://doi.org/10.3390/batteries2030028) describes rate
characterization of intact cells and harvested electrodes against lithium.
Finite-current half-cell RPT is an electrode-potential lead, not a verified
equilibrium OCP table. No MAT member was extracted: branch mapping, coordinates,
reference conventions, channels and donor identity remain open. The paper's
degradation emulations are not measured ageing.

The ZIP directory required three HTTP Range requests totalling 20,604 metadata
bytes, rather than the full 73,115,393-byte archive. Provider MD5 was not
independently recomputed. [API metadata](https://zenodo.org/api/records/60232)
reports `cc-zero`; the [export](https://zenodo.org/records/60232/export/json)
identifies CC0 1.0.

## Beginning-of-life pseudo-OCV, pulse and EIS

[Zenodo 8369275](https://zenodo.org/records/8369275) lists 13 files. Whole-cell
pseudo-OCV uses 0.05C and an interpolated SOC grid; it is not electrode OCP.
EIS companions describe frequency and real/imaginary impedance at 50% SOC.
Pulse companions describe time and voltage. The 25 degC chamber condition does
not establish a measured thermal trace. MAT and CSV are companion representations,
not extra cells. File contents, dimensions and cross-file row identity remain
unchecked. No license was found in the inspected page, API or export; keep
observations external and resolve reuse permission before redistribution.

## Ageing and repeated reference tests

[Zenodo 7896429](https://zenodo.org/records/7896429) lists 116 H5 cell files and one
protocol PDF. All are linked; the approximately 27.1 GB payload stays external.
The source reports 37 ageing profiles and repeated reference testing. Its PDF
documents voltage, current, temperature, capacities and step index; raw H5 groups,
time axes, units and actual column coverage remain unchecked.

The stopping rule is 70% remaining capacity **or project end**; not every cell
is certified to reach EOL. Initial reference tests span five temperatures and
subsequent reference tests use 25 degC; ageing-load conditions are separate.
Zero-current storage arms in Table 2 support the calendar-ageing category. This
classification follows documented protocols, not inspected H5 histories.

Table 2 repeats `2_013`/`2_014`/`2_015` across different profile rows and prints
`2_57` in L221 while the source file is `2_057.h5`. These ambiguities are retained;
no authoritative per-cell profile map is imported or silently corrected. No
US06 or EIS file is identified by the reviewed documentation.

## Multi-rate discharge and surface temperature

[Mendeley v2](https://data.mendeley.com/datasets/kxsbr4x3j2/2) is a three-model
deposit. The [paper](https://doi.org/10.1016/j.dib.2021.106894) identifies its NCA
section as NCR18650B. Fifteen selected NCA/k1 workbooks cover 0.05C, 1C, 2C, 3C and
5C in each observed `05degC`, `25degC` and `35degC` folder. This does not certify
a complete six-cell matrix. CCCV preparation is not a multi-rate charge sweep;
the LFP section's higher rates are not NCR18650B rates. Electrical and surface-
temperature channels are source-documented; no XLSX header/payload was read.

## Find sources and exact links

```bash
ebp datasets NCR18650B
ebp datasets --material NCA --aging-status available --json
ebp datasets --files --material NCA --test-type eis --json
```

```python
from ebp import Catalog

catalog = Catalog()
for dataset in catalog.search_datasets(material="NCA", aging_status="available"):
    print(dataset["title"], dataset["aging_data"])
    for item in dataset["file_links"]:
        print(item["source_path"], item["url"])
```

`aging_data.status` is `available`, `not_reported` or `unverified`; not reported
is not proof of absence. Kinds, source evidence and representative `file_paths`
accompany availability. With `--files`, the ageing filter applies to the parent
source, not every file: protocol PDFs and reference companions can also be
returned. `full_cell_data()` still reads existing packaged tests only. Nothing
in this addition downloads new experimental observations automatically.
